# Links and the dashboard

Links are shortcuts to other web pages: a Companion button page, a room's camera control, a floor plan, the lighting desk's notes. Open **Links** in the console (admins and managers).

![The Links page: a row to add a link with label, URL, room, board and kind, and three links below it](/static/kb/console-links.jpg)

## Add a link

1. Type a **label** (what people see) and the **URL**.
2. Pick where it shows:
    - **Room: Whole site**: on the console's Dashboard, for everyone.
    - **Room: a room**: only in that room's tech workspace, in the **Links** window.
3. Pick a **board**: *public* for everyone, *admin* for admins only.
4. Pick a **kind**. It only decides the heading the link is grouped under.
5. Press **Add**.

Change a link and press **Save**, or **Delete** it.

## Where techs find them

In the tech workspace, open the **Links** window from the **Layout** menu. Links are cards with a search box: this room's links first, then the rest of the site's. Each card shows whether its address answers.

![The Links window in the workspace: a search box, then this room's links (Companion buttons, Lighting desk notes) and everything else (Venue floor plan)](/static/kb/workspace-links.jpg)

You don't have to add any links: the workspace works without them.
