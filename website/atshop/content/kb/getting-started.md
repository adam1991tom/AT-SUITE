# From buying to your first show

Six steps take you from a licence key to a venue ready for its first show. Most venues do it in an afternoon.

1. **Get a licence key.** [Create an account](/register?next=/account) and start the free 30-day trial, or [choose a plan](/pricing). Your key appears under **Licence key** in [your account](/account) and arrives by email. See [Licence keys](/docs/licence-keys).
2. **Get a server.**
    - *Managed hosting*: we set up your server and email you a setup link. Skip to step 3. See [Managed hosting](/docs/managed-hosting).
    - *Your own server*: install AT SUITE with one command. See [Install on your own server](/docs/self-hosted-install).
3. **Run the setup wizard.** Open your server's address, enter the organisation, the venue, the rooms (one per line) and the first admin account, then paste the licence key. See [The setup wizard](/docs/setup-wizard).
4. **Add your people.** In the console, open **People** and add an account for each tech and manager. See [People, roles and passwords](/docs/people-and-passwords).
5. **Set up the laptops and screens.** Install the [AT SUITE app](/docs/laptop-app) on each tech laptop, and [add the stage screens](/docs/pair-a-screen) by typing the code each one shows.
6. **Rehearse.** On every laptop, sign in, pick the room and run a cue on the timer; check the stage screen follows it. Send a help call from one room and answer it from another. Then open the dashboard and check the [pre-show check](/docs/preshow-check) is green.

![The setup wizard's first page: organisation name, venue name and time zone](/static/kb/setup-wizard.jpg "The setup wizard runs the first time you open a new server.")

> **Tip:** Print the tech quick-start card (`/guide/tech` on your server, also linked from **Laptops & screens → Add laptops**) and leave one by each laptop. It fits on one A4 page.
