# Troubleshooting

Find what you see, then try the fixes in order. Still stuck? Ask the AI helper (**Help** in the top bar), send a help call, or [report a bug](/docs/bug-reports).

## Signing in

| What you see | Try this |
|---|---|
| **Wrong username or password** | Usernames are what an admin set up (like `amy`), not your full name. Passwords care about capitals |
| Forgot your password | **Forgot password?** on the sign-in screen. A manager resets it and you sign in with `ChangeMe`. See [People and passwords](/docs/people-and-passwords) |
| **Too many requests** | Too many sign-ins from one place in a minute. Wait a minute and try again |
| A page from the console is missing | It's for another role, or that part of AT SUITE is switched off. See [Who can do what](/docs/roles-and-permissions) |

## Laptops and screens

| What you see | Try this |
|---|---|
| Top bar says *connecting* | The laptop can't reach the server. Check the network. The timer keeps working meanwhile. See [When the network drops](/docs/when-the-network-drops) |
| Pre-show check: laptop **Offline** | Is it on, awake and on the venue network? Restart the app from the AT SUITE icon by the clock |
| Pre-show check: **not started today** | The tech signs in and picks the room. See [Start the day](/docs/start-the-day) |
| Wrong room on a laptop | A manager or admin moves it from **Laptops & screens**. See [Watching laptops and screens](/docs/laptops-page) |
| Laptop limit reached when enrolling | Remove laptops you no longer use, or move to a bigger plan. See [Licence keys](/docs/licence-keys) |
| A stage screen is blank or frozen | See [A stage screen goes blank](/docs/scenario-blank-screen) |
| A screen shows **nothing yet** | Pick a view for it in the workspace's **Screens** window |
| Screen code not accepted | Codes last 15 minutes. Reload the pairing page for a fresh code. See [Add a stage screen](/docs/pair-a-screen) |

## The timer

| What you see | Try this |
|---|---|
| Stage screen doesn't change when you press GO | Is **Blackout** on? Is the screen in the right room and online? |
| The timer is flashing | It's past zero, or in the danger time with **Flash the timer at danger** or **Blink** on. **Stop** clears it |
| Cues are wrong after **Send this day to the timer** | It replaces the cue list with the day's sessions. Edit the cues, or rebuild them. See [Build the running order](/docs/cue-list) |
| The show day or nightly jobs run at the wrong hour | Check the site's time zone on **Rooms**. See [Rooms and sites](/docs/rooms-and-sites) |

## Captions

| What you see | Try this |
|---|---|
| **Caption engine is off** | An admin turns captions on for the room, and checks **Console → Captions** |
| **Send my mic** is greyed out: "Browsers only allow the microphone over https" | Use the AT SUITE app, or open the workspace at the server's `https://` address. See [Install](/docs/self-hosted-install) |
| Nothing shows on the caption screen | Is the mic **live** in the Captions card? Is **Captions on for this room** ticked? **Send a test line** to test the screen alone |
| Pre-show check: **very quiet** | Wrong input, a muted send, or gain too low. See [Caption settings](/docs/caption-settings) |
| Names come out wrong | Add them to **Vocabulary** and click misheard words to correct them |
| Gibberish during music | Tick **Show music and filler noises as [MUSIC]**, or feed speech mics only |
| My mic stopped and says someone took over | Only one laptop sends the mic for a room. Agree who does it |
| Transcript has gone | Transcripts are deleted 12 hours after they end. See [Transcripts](/docs/transcripts) |

## Presenters

| What you see | Try this |
|---|---|
| Presenter's link isn't valid | The event was archived, or a new link was made. Send the current one. See [Presenter links](/docs/presenter-links) |
| Upload fails | Check the size limit in **Presenters → Settings**, or use **Upload for them** |
| Slides didn't reach the presentation laptop | Only approved files sync. Is room sync running with the right code? See [Room sync](/docs/room-sync) |

## Admin

| What you see | Try this |
|---|---|
| An update isn't installing | **Settings → Updates**: check the mode, then **Check now**. Versions only ever go up. See [Updates](/docs/updates) |
| A licence banner | See [The licence is ending](/docs/scenario-licence-ending) |
| AT SUITE is locked | Only **Licence** works until a key is in. Nothing is deleted. See [Licence keys](/docs/licence-keys) |
| The AI helper isn't in the Help menu | **Settings → AI helper → Turn on the AI helper**. See [Set up the AI helper](/docs/ai-helper-setup) |
| The AI helper's answers are vague | Add venue notes. A private AI model gives fuller replies |
| Restoring a backup | See [Backups](/docs/backups) and [Move to a new server](/docs/scenario-new-server) |

## Still stuck

Note the version from **Settings → About**, what you did and what you saw, and [report a bug](/docs/bug-reports). For your subscription, see [Billing and your account](/docs/billing) or [contact us](/contact).
