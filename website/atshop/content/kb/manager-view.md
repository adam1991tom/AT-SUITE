# The manager view

The manager view is what an admin or manager gets when they sign in on a laptop with the AT SUITE app, or open **Manager view** at the bottom of the console (or `/manage` on a phone). It's the whole venue on one screen, in the same movable windows as the tech workspace.

![The manager view: every room's timer along the top, help requests and chat on the right, and the pre-show check with each room's laptops and screens below](/static/kb/manager-view.jpg "The manager view, as it starts.")

## The windows

It starts with these on screen:

- **Rooms**: every room's timer live, the cue on now and next. **Timer ↗** opens the room's stage view.
- **Help requests**: open help calls with **On my way**, **Reply** and **Resolved**.
- **Pre-show check**: the same check as on the console dashboard. The tab shows how many things aren't working.
- **Laptops**: every laptop and screen, online or offline, its room and who's on it, Main or Backup.
- **Chat**: the crew chat.

And these wait in the taskbar until you want them:

- **Password resets**: everyone who pressed Forgot password, with **Reset to ChangeMe**.
- **Recent activity**: the last 40 entries of the audit log.
- **Console pages**: a tile for each console page you can open.

## Make it yours

- **Choose what to show**: tick the windows you want. Unticked ones wait in the taskbar.
- Drag a window by its title to move it, dock it beside another, or make it a tab. Use the **Layout** menu to save a layout. See [Windows and layouts](/docs/workspace-tour).
- Your layout is kept on that device, so a phone and a laptop can each have their own.

![The manager view on a phone: windows stacked one under another](/static/kb/manager-phone.jpg "On a phone the windows stack.")

## Buttons at the top

- **Full console** opens the console.
- **Work a room** (on a laptop with the app): signs you out of the manager view and starts the laptop's day in a room, as a tech.
- **Sign out**.

> **Tip:** A show caller or production manager can run the whole venue from a phone in the manager view: help calls, chat and the pre-show check are all there.
