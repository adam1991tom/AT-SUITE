# Scenario: run a conference day

**The day:** *Future of Events Summit*, four rooms, doors at 09:30, keynote at 10:00 in Main Hall, workshops in the studios, captions on the keynote.

## The day before

- **Presenters**: the running order is in (imported from the client's spreadsheet, see [Events and the running order](/docs/presenters-events)) and presenters have their links.
- **File review**: approve what's uploaded. Reject with a note anything that needs changing.
- **Room sync** is running on each room's presentation laptop (see [Room sync](/docs/room-sync)).
- **Captions**: the keynote speakers' names and the sponsors' names are in Main Hall's vocabulary.
- **Handover notes** in each room for the morning crew.

## 07:30 crew call

Each tech signs in on their room's laptop, checks the room, chooses Main PC or Backup PC and presses **Start**. They read the room's handover notes (the **NOTES** count in the top bar).

## 08:00 load the running order

In each room: **Sessions → Send this day to the timer**. One cue per session, timed from the schedule, with the presenters in the notes. Check the cue list and adjust lengths if the client's times were rough. See [Build the running order](/docs/cue-list).

## 08:30 pre-show check

The duty manager opens the console **Dashboard** or the **manager view**. Fix red, then amber, until every room is green or grey. See [The pre-show check](/docs/preshow-check). Then, room by room:

- Send a test stage message and hide it.
- Send a caption test line in Main Hall and read it from the back.
- Play the walk-in loop from the show files.

## 09:30 doors

Load cue 1 (*Doors and walk-in*) on each timer. As presenters arrive they press **I'm here** on their page, or the tech presses **Check in** in **Sessions**.

## 10:00 the keynote

1. The Main Hall tech presses **GO**. The stage screens, backstage and the AT Overlay all count down.
2. Captions: **Send my mic**, and **Start recording** if the client wants the transcript. See [Caption a keynote](/docs/scenario-caption-keynote).
3. Five minutes left: the timer turns amber. One minute: red. If they run over, it counts up in red with a minus sign.
4. To wrap them up: type "Please wrap up" and **Show**, or **Blink** the timer.

## During the day

- A problem? **Help** in the top bar. The duty manager presses **On my way**. Nobody answers in 2 minutes? It goes out again to every laptop. See [Help calls](/docs/help-calls).
- Late slides? See [Late slides from a presenter](/docs/scenario-late-slides).
- A blank screen? See [A stage screen goes blank](/docs/scenario-blank-screen).
- Crew changeover at lunch: see [Shift handover](/docs/scenario-shift-handover).

## End of the day

See [End of the show day](/docs/scenario-end-of-show): stop the mics, export transcripts, leave notes, make the show report.
