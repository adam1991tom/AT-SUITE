# Chat with the crew

Chat looks and works like Messenger. Each room has its own chat, there's one for all crew at the venue, and signed-in people can message each other directly.

![The Chat window in the workspace: the chats along the top (All crew, Main Hall, Studio 1, Studio 2, Boardroom), then the Main Hall chat with message bubbles and Seen by Ben Okafor](/static/kb/workspace-main.jpg)

## The chats

- **# All crew**: everyone at the venue.
- **A room** (like *Main Hall*): the techs in that room and the managers. Your own room is picked when you open Chat.
- **Direct messages**: between two people with accounts. Start one with **New message** in the console's chat list. (A tech laptop signed in with a name only can't send direct messages.)

A number on a chat counts the messages you haven't read.

## Send a message

1. Type in the box at the bottom. <kbd>Enter</kbd> sends; <kbd>Shift</kbd>+<kbd>Enter</kbd> starts a new line.
2. Pick how much it matters, next to the box:
    - **Normal**
    - **Important**: an amber border and a flag.
    - **Urgent**: a red border and a flag.
3. 📎 attaches a file or a picture; 😊 adds an emoji.

Your messages are on the right in the brand colour; everyone else's are on the left with their initials. Your latest one says **Sent**, then **Seen by** and who has read it.

## In the console

**Chat** in the console has every chat on the left, with each one's latest message and how long ago it was sent, and the chat on the right.

![The console's Chat page: chats on the left with All crew selected, and an important message about doors and crew lunch](/static/kb/console-chat.jpg)

## Pop-ups and the Main PC

On a **Backup PC**, new messages in your room, crew-wide messages and urgent messages pop up bottom-right, silently. The **Main PC** never shows them. See [Notifications, pop-ups and the bell](/docs/notifications).

## How long messages are kept

An admin can delete messages older than a number of days (**Settings → General**), and see and delete direct-message chats (**Settings → Chat**) without reading them.
