# The audit log

Everything that changes something is recorded: who did it, what, and when. Settings changed, people added, passwords reset, laptops moved, licences added, backups made and restored, transcripts cleared, cue lists replaced, presenters' files approved, and more.

![The audit log: a filter box, Download as PDF, and a table of When, Who, What and Detail](/static/kb/console-audit.jpg "Console → Audit log.")

## Read it

**Console → Audit log** (managers and admins). The newest 200 entries show, newest first:

- **When** it happened,
- **Who** did it (a person's name, a laptop, or `system` for things AT SUITE does itself, like clearing old transcripts),
- **What**: a short name for the action, like `presenter.to_timer` or `captions.transcripts_deleted`,
- **Detail**.

Type in **Filter** to show only entries with that word: a person, a room, `password`, `licence`.

## Download it

**Download as PDF** gives every entry, not only the 200 on screen, newest first. With a filter typed, the PDF has every entry matching it. Use it for a client's audit, an incident review, or your own records.

The manager view's **Recent activity** window shows the last 40 entries.

> **Note:** Passwords, keys and codes are never written to the audit log.
