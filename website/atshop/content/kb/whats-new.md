# What's new

The latest changes, newest first. Your server updates itself (see [Updates](/docs/updates)); **Settings → About** shows which version it runs.

## 1.25.0: logos and pictures in the layout designer, BDNG is gone

- Upload a **logo** and a **background picture** for a view straight away: no need to save the view first. The Logo part has its own **Upload…** button too.
- A new **Picture** part for sponsors' logos, photos and show graphics: as many as you like, each with its own picture. Drop picture files onto the screen to add them. See [Logos and pictures](/docs/layout-designer#logos-and-pictures).
- **Save as new** copies a view's pictures.
- The **BDNG sponsor clock** is no longer a built-in timer view, and **BDNG style** is no longer a ready-made layout in the layout designer. A screen or link still set to it shows the [Standard view](/docs/timer-views) instead. Layouts you already made from BDNG style are yours and stay.

## 1.24.0: the knowledge base and the manual

- This **help centre**: every screen and button step by step, with pictures, tips and show-day [scenarios](/docs/scenario-conference-day). Search it from the top of [the help centre](/docs).
- The same pages are **inside AT SUITE** as the manual at `/guide/manual`: the console's side bar and the workspace's **Help** menu link to it, and it works with no internet.
- The **AI helper** answers "how do I..." questions about AT SUITE from the manual, step by step. See [Ask the AI helper](/docs/ai-helper).

## 1.23.0: backups of the whole server, full venue report

- **Backups** are now the whole server in one zip: rooms, people, chat and files, timers and views, presenters' files, show reports, laptops and screens, settings and the licence. The server backs itself up every night at 02:00 and keeps the newest 14. See [Backups, restore and moving server](/docs/backups).
- **Restore** puts the whole server back from a backup, including one from another server, so moving to new hardware is a download and an upload. See [Move to a new server](/docs/scenario-new-server).
- **Full venue show report**: every room side by side, then each room in full, in one PDF. Reports now download as PDF. See [Show reports](/docs/show-reports).
- **Audit log as a PDF**: every entry, or only the ones matching the filter. See [The audit log](/docs/audit-log).
- The Servers page and helper servers are gone: captions are made on the laptops, so the server needs no help.

## 1.22.0: the licence renews itself

- Keys from the website check in once a day, so a renewed key installs itself. **Licence** shows the daily check and has **Check now**. See [Licence keys](/docs/licence-keys).

## 1.21.0: the layout designer

- Make your own timer views by placing the timer, title, clock, message, logo and more on a 16:9 screen. See [The layout designer](/docs/layout-designer).
- The Timers page has five tabs: Live, Screens, Quick messages, Views and Layout designer.

## 1.20.9: Messenger-style chat

- Chat uses message bubbles, with "Sent" and "Seen by". Handover notes, links and help calls are cards. The bell counts what's new. The console's Help requests page is a help desk. See [Chat with the crew](/docs/chat).

## 1.20.8: the manager view

- Admins and managers get their own desk of windows in the app, or at `/manage` in any browser. See [The manager view](/docs/manager-view).

## 1.20.7: clearer timer buttons

- GO and Start are green, Pause amber, Stop red. The timer only flashes once time is up (or in the danger time with Blink on). Admins and managers can edit the quick messages.

## 1.20.4: the AI helper is a chat

- Say what's wrong and keep talking until it's fixed. It asks questions to narrow the fault down, offers fixes that worked before, and can send a help call for you. See [Ask the AI helper](/docs/ai-helper).

For every change in every version, see the release notes on the [releases page](https://github.com/adam1991tom/AT-SUITE-releases/releases).
