# A tour of the console

The console is AT SUITE's main web page: open your server's address in a browser (for example `http://10.0.0.10:8080`) and sign in. Admins and managers run the venue from here; techs mostly use the [tech workspace](/docs/workspace-tour) on their laptop.

![The console dashboard: the sidebar on the left, the pre-show check with each room's laptops, screens and caption mic, and a live timer card for each room](/static/kb/console-dashboard.jpg "The console's Dashboard.")

## The sidebar

What you see depends on your role (see [Roles and permissions](/docs/roles-and-permissions)) and which parts of AT SUITE are switched on.

**Live**

| Page | What it's for |
|---|---|
| **Dashboard** | The pre-show check, every room's timer live, and the venue's links |
| **Chat** | The crew chat: everyone, each room, and direct messages. The number is unread messages |
| **Help requests** | Every help call, open and answered. It turns red while one is waiting |
| **Timers** | Every room's timer and cue list, timer views, the layout designer and the stage screens |
| **Presenters** | Events, running orders, presenters' slides, imports |
| **Captions** | The speech engine, each room's captions, and transcripts |
| **Show reports** | A PDF of a room's or the whole venue's show day |

**Venue**

| Page | What it's for |
|---|---|
| **Rooms** | Sites and rooms (add, rename, lock a room) |
| **Laptops & screens** | Every laptop and screen: online, which room, who's on it. Admins add laptops and set up overlay laptops here |
| **People** | Accounts, roles and password resets (the number is people waiting for a reset) |
| **Links** | The buttons on the dashboard and in each room's workspace |

**Site** (admins)

| Page | What it's for |
|---|---|
| **Settings** | General, Look, Chat, AI helper, API keys, Updates and About |
| **Bug reports** | Reports from the crew (the number is open ones) |
| **Licence** | Your licence key, plan and expiry |
| **Backups** | Nightly and on-demand backups, download and restore |
| **Audit log** | Who did what, and when (managers too) |

At the bottom: **Manager view** (the window layout for running a show, see [The manager view](/docs/manager-view)), **Tech workspace** (work a room yourself), your name and **Sign out**.

## The dashboard

1. **Pre-show check**: every laptop, screen and caption mic, room by room, green, amber or red. It refreshes every 5 seconds. See [The pre-show check](/docs/preshow-check).
2. **Room timers**: each room's timer as it runs, the cue on now and next, and anything on stage. **Standard ↗** opens the room's stage view.
3. **Links**: the venue's links, grouped (a room's, Devices, Tools...). The dot on each shows whether the address answers.

**Open the workspace** takes you to the tech workspace. Admins have **Edit links**.

## Alerts on any page

Wherever you are in the console, a pop-up tells you when:

- a help call comes in, or is still unanswered after a few minutes,
- someone forgot their password,
- a bug report arrives (admins).

A licence that's about to end shows as a banner across the top.

> **Tip:** Keep the console open on a second screen at the production desk, on the Dashboard. You'll see a room go red before anyone calls.
