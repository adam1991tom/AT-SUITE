# Caption screens and the overlay

Every room has three ways to show its captions. Each has its own look, set in [Caption settings → Appearance](/docs/caption-settings).

![A caption screen: two lines of white text on a black band at the bottom of a dark screen](/static/kb/screen-captions.jpg "The audience caption screen.")

| Screen | Address | Use it for |
|---|---|---|
| **Audience screen** | `/captions/<room>` | A screen or projector the audience reads: a side screen, a TV by the stage, an LED wall |
| **Overlay** | `/captions/<room>/overlay` | A transparent page for a video mixer (OBS, vMix, a streaming PC): the captions sit over the picture |
| **Subtitle bar** | `/captions/<room>?layout=bar` | A strip of captions in a band, for a lower third or a narrow screen |

`<room>` is the room's number. You never need to type it: the links are in the workspace's **Captions** window (**Caption screen**, **Overlay (for a video mixer)**) and in **Caption settings → Live**.

## On a stage screen

The easiest way is a paired screen:

1. In the workspace, open **Add a screen** and pair the screen with the code it shows (see [Pair a stage screen](/docs/pair-a-screen)).
2. On **Screens**, set that screen's view to **Captions**.

The screen follows the room. If the room's captions change look, the screen changes with it. A Linux screen gets captions the same way, through **Add a screen**.

You can also open the audience screen's address in any browser on the venue network and make it full screen (F11).

## In OBS or vMix

1. Copy the **Overlay** link from the Captions window.
2. In OBS: **Sources → + → Browser**, paste the address, and set the width and height to your canvas (1920 × 1080). In vMix: **Add Input → Web Browser** with the same address.
3. Put the source above your camera or slides. The page is transparent: only the captions show.

> **Tip:** Set the overlay's **Position** and **Size** in Caption settings → Appearance → Overlay rather than cropping in the mixer. Then every mixer using it looks the same.

## When the server can't be reached

With the **AT SUITE app**, tick **Feed this room's screens from this laptop** in the Captions window. The window then shows this laptop's own address for the room's caption screen. Point a caption screen at that and it shows this laptop's captions even if the server goes down. See [When the network drops](/docs/when-the-network-drops).

## The AI disclaimer

Tick **AI disclaimer** in Appearance to show a small "Captions generated by AI, may contain errors" note in the corner. Some clients ask for it; it's off by default.

## Check it before doors

- Send a test line (**Send a test line**) and read it from the back row.
- Check the overlay over a busy picture: if it's hard to read, raise **Background opacity**.
- Press **Clear the screens** before the audience comes in.
